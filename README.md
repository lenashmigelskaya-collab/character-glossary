# 📜 Интерактивный Глоссарий Персонажей (Character Glossary CRUD)

Веб-приложение в стилистике готических свитков для создания, хранения, поиска и просмотра досье персонажей из различных вселенных (игры, литература, визуальные новеллы). 

Проект выполнен на чистом **HTML5, CSS3 и Vanilla JavaScript** без использования сторонних фреймворков и библиотек.

🔗 **[Открыть живую версию проекта (GitHub Pages)](https://github.io)** 

---

## ✨ Реализованный функционал (CRUD)

* **Главное меню и рандомайзер (`index.html`):** интерактивная навигация с CSS-анимацией и случайный выбор карточки персонажа из всей базы (включая созданных пользователем героев).
* **Интерактивный список с аккордеоном (`charlist/`):** 
  * Раскрытие краткой сводки о персонаже по клику на перо.
  * Переход к полному досье по клику на имя.
  * Автоматическая пагинация списка (по 5 персонажей на страницу).
* **Живой поиск (`search/`):** мгновенная фильтрация персонажей по имени в реальном времени без перезагрузки страницы с динамическим пересчётом страниц.
* **Создание и редактирование карточек (`create/`):**
  * Загрузка изображений с устройства через `FileReader API` (Base64) с автоматической стилизацией в чёрно-белый портрет и жёстким контролем рамок (`object-fit: cover`).
  * Режим редактирования существующих карточек через параметры URL (`URLSearchParams`).
  * Автоматическая разбивка объёмного текста биографии на страницы свитка без разрыва слов с интерактивным перелистыванием.
* **Удаление и хранение данных (`LocalStorage API`):** сохранение пользовательских карточек в памяти браузера и удаление записей с подтверждением.
* **Экспорт карточки в файл (`Blob API`):** генерация и скачивание автономного `.html`-файла с оформлением, текстом и вшитым портретом персонажа.

---

## 🛠 Стек технологий

* **HTML5** — семантическая разметка, формы, атрибуты данных (`data-*`).
* **CSS3** — Flexbox-вёрстка, ключевые кадры анимации (`@keyframes`), CSS-фильтры (`filter: grayscale`), кастомная стилизованная графика.
* **JavaScript (ES6+)** — работа с DOM, обработка событий, `LocalStorage API`, `FileReader API`, `Blob API`, `URLSearchParams`.

## 📂 Структура проекта

```text
├── index.html          # Главная страница меню
├── menu.css / menu.js  # Стили меню и логика рандомайзера
├── charlist/           # Список всех персонажей (аккордеон, пагинация, удаление)
├── search/             # Страница живого поиска по базе
├── create/             # Форма создания/редактирования и шаблон динамической карточки
└── vi/, kieran/...     # Индивидуальные страницы предустановленных персонажей
```
